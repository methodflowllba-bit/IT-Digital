# IT Digital — Brasformer

Interface web responsiva para consulta de instruções de trabalho. Página inicial com seis opções e navegação pelos setores Baixa Tensão, TC, TP, Resina, Montagem e Testes.

## Abrir no computador

Salve os arquivos em `C:\Users\DeLL\Documents\Brasformer\IT-Digital` e abra `index.html` no navegador. Não exige instalação de dependências.

## GitHub Pages

Publique os arquivos na raiz do repositório. Em Settings → Pages, selecione Deploy from a branch, branch main e pasta /(root).

## Escopo desta versão

Cabeçalho Brasformer, menu principal, seleção e filtro de setores, voltar e ajuste de tamanho do texto. Busca de ITs, produtos, favoritos e QR Code mostram o estado de catálogo vazio; cadastro, arquivos e leitura por câmera serão implementados quando o conteúdo e os requisitos forem definidos. Não há banco de dados nesta versão.
